# FreeFowl Arcade

Free browser games — no downloads, no installs, and nothing to buy.

Play at [freefowl.com](https://www.freefowl.com/).

## Games

- [Free Fowl](https://www.freefowl.com/freefowl/) — a 4-team bird battle. Play solo against bots or online with friends.
- [Ronin: The Cursed March](https://www.freefowl.com/ronin/) — side-scrolling action through the underworld.
- [The Long Migration](https://www.frefowl.com/migration/) — a story-driven Free Fowl adventure.
- [The Coop](https://www.freefowl.com/coop/) — single-player survival horror in an abandoned poultry plant.
- [Dreadwarden](https://www.freefowl.com/dreadwarden/) — a dungeon-defense game where you set the monsters' ambush.
- [Night Shift](https://www.freefowl.com/nightshift/) — top-down horde survival across eleven office floors.

## Development

This is a static site with no build step. Changes pushed to `main` deploy live.
